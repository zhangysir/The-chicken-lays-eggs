# stock-lot-tracker PRD v0.2

> 重建说明：原 `stock-lot-tracker-PRD.md`（v0.1）未提交进仓库，仅以 6 个 FR issue 正文的「来源」引用存在。本 v0.2 由其反推重建，并据评审决议补充两项决策（持久化=本期内存版；当前价=每批次一个价）。
> **本文件即需求单一事实源。后续任何调整须通过 issue + PR 修改本文件**（流程见 `CONTRIBUTING.md`）。

## 1. 项目目标

一个从零开始的**股票批次（lot）成本追踪**小工具：记录买卖流水，按批次核算含费单位成本、持仓状态与盈亏（已实现 / 未实现）。MVP 形态为纯前端静态页。

## 2. 范围

- 本期交付：FR1–FR6（买入 / 卖出 / 批次 / 持仓 / 盈亏 / 当前价）。
- 非目标（见第 7 节）：自动拉取行情、数据持久化。

## 3. 核心概念

- **交易流水（transactions）**：每一笔买 / 卖记为一条。
- **批次（lots）**：每一笔买入自动生成一条批次；卖出从指定批次扣减。
- **指定批次卖出**：卖出时由用户下拉选择 `lot_id`，可卖出该批次中的一部分。

## 4. 功能需求（FR）

| 编号 | 需求 | 依赖 |
|------|------|------|
| FR1 | 录入买入：记录日期 / 股票 / 价格 / 股数 / 费用 | 无 |
| FR2 | 自动生成批次：含费单位成本 | FR1 |
| FR3 | 录入卖出（指定批次，可部分卖出） | FR2 |
| FR4 | 批次持仓明细：每批成本 / 剩余 / 状态 | FR2、FR3 |
| FR5 | 盈亏汇总：已实现 + 未实现 | FR3、FR4、FR6 |
| FR6 | 每批次录入当前价（供未实现盈亏用） | 无 |

## 5. 数据模型

### 5.1 transactions（交易流水表）

| 字段 | 说明 |
|------|------|
| `date` | 成交日 |
| `code` | 股票代码 |
| `name` | 股票名称 |
| `price` | 成交价 |
| `shares` | 成交股数（整数） |
| `fee` | 佣金 + 印花税 + 过户费 |
| `type` | 买入 / 卖出 |
| `lot_id` | 买入时为空；卖出时填指定批次 |

### 5.2 lots（批次表）

| 字段 | 说明 |
|------|------|
| `lot_id` | 如 `600519-20260901-①` |
| `buy_date` | 买入日 |
| `buy_price` | 买入价 |
| `buy_shares` | 买入股数 |
| `remain_shares` | 剩余股数（初始 = buy_shares） |
| `unit_cost` | 含费单位成本 = (buy_price × buy_shares + fee) ÷ buy_shares |
| `current_price` | 该批次当前价（FR6 录入，用于未实现盈亏） |
| `status` | 未平 / 部分平 / 已平 |

### 5.3 派生视图

- **持仓明细**：按股票汇总 `status ≠ 已平` 的批次，展示 `lot_id` / 单位成本 / 剩余股数 / 状态。
- **盈亏**：
  - 已实现 = (卖价 − 该批 `unit_cost`) × 卖出股数
  - 未实现 = (`current_price` − 剩余 `unit_cost`) × 剩余股数（逐批次计算）

## 6. 示例（验收基准）

- 买入 A：10 元 × 100 股，费 0 → 批次 A `unit_cost` = 10.00，`remain` = 100，未平
- 买入 B：12 元 × 200 股，费 0 → 批次 B `unit_cost` = 12.00，`remain` = 200，未平
- 卖出 B：13 元 × 100 股，指定批次 B → 批次 B `remain` = 100，部分平；批次 A 不变
- 持仓明细：A 100 股 / 10.00 / 未平；B 剩余 100 股 / 12.00 / 部分平
- 已实现盈亏 = (13 − 12) × 100 = **+100 元**；未实现按各批 `current_price` 计算

## 7. 非目标

- 自动行情拉取（本期不做，FR6 用手动价兜底）
- 数据持久化（本期用内存态，刷新即清空；持久化作为后续独立 FR 实现）

## 8. 决策记录（v0.2 评审决议）

- **持久化**：本期不做，先用内存态（JS 运行时状态），后续单独 FR 补 localStorage / IndexedDB。
- **当前价粒度**：每批次一个当前价（`lots.current_price`），而非全局单一价。
- **PRD 为动态文档**：后续调整经 issue + PR 修改本文件，不私下改需求。
